# Стена Долгостроя (Wall Mini App)

Интерактивная кирпичная стена ожидания приложения для платформы [Gem Mini Apps](https://gem.bot).

Пользователи заходят и оставляют свои теги баллончиком с краской на стене с подсчетом дней без коммитов.

## Содержимое репозитория:
- `index.html` — хостинг GitHub Pages
- `app.js` — клиентский фронтенд с физикой частиц баллончика, звуками, виброоткликом и выбором цветов
- `gem-app.js` — компактный коннектор для развертывания через Telegram бота `@gembot`
